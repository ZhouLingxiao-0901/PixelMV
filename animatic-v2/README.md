# 《刻在我心底的名字》· 动态分镜 V2

歌词驱动的 16-bit 像素动态分镜（Animatic）。使用真实 MP3 作为主时钟，从歌曲开头连续播放到歌后留白与结束文字；V1 与 `animatic-v1/` 保持原样。

- 本地地址：<http://127.0.0.1:8123/animatic-v2/>
- 页面标题：**刻在我心底的名字 · 动态分镜 V2**
- 画布：640 × 360，`imageSmoothingEnabled = false`，就近整数放大
- 总时长：**05:25.0**（325.0 秒）
- 真实音轨：`assets/audio/卢广仲 - 刻在我心底的名字.mp3`，实测 `audio.duration = 320.165792`
- 歌后留白：320.166 – 322.0 秒静默；322.0 秒起只显示「珍惜那些在你生命中的名字」

> 这是 **Animatic V2**，不是最终逐帧动画。镜头、景别、歌词关系与声音关系已经实际播放验证；角色表演仍复用现有精灵表，近景中的手、腿、伞、钥匙等为程序化像素分镜，属于待替换的临时表演。

## 这一版改了什么

- **以歌词为叙事脊柱**：先读 LRC 的 41 句歌词，再按句意组织镜头；九段真实经历全部保留，但不再按时间顺序平铺，而是用现在 / 过去、城市 / 教室、雨 / 暖光的交叉剪辑串起来。
- **名字悬念不变**：26.9 秒他问「你叫什么名字？」，31.9 秒她刚说「我……」就切走；直到 283.1 秒的旧毕业纪念册才以「【男主名字】」「【女主名字】」占位揭晓。全片不填真实姓名。
- **歌词字幕进入画面**：运行时读取原 LRC，逐句淡入淡出，底部安全区、像素描边、按画面亮度自适应压暗；不显示制作名单。
- **对白克制**：只在说话者头部附近出现一个像素气泡；疫情聊天在手机屏幕内滚动；表白始终是电话，没有改成当面告白。
- **重剪徒步段**：从城市人海到山顶初吻之间切成 9 个不同景别 / 不同内容的镜头，解决原来「长时间同一构图 + 整幅平移」的拖沓。

## 歌词层（实际实现）

- **解析**：运行时 `fetch` 原 LRC，按 `[mm:ss.xxx]` 解析，过滤空行、制作名单与 NetEase JSON 残留；实际载入 **41 句**，`lyricError = null`。
- **显示偏移**：画面层统一 **+0.08 秒**（`displayStart = sourceStart + 0.08`）。这是显示层补偿，**没有改写源 LRC**。
- **停驻**：单句最多显示 7.5 秒，句间自然淡出；最后一句 283.115 秒后不再出现歌词，320.166 秒后完全停止。
- **版式**：底部安全区从 `y = 316` 开始，文字基线 `(320, 334)`，字号 16，系统字体渲染后二值化，带深色描边；不使用 KTV 逐字变色。
- **对比度**：逐帧采样底部区域亮度，绘制阶梯状半透明压暗带，亮场景（初吻、毕业册、山顶）也不会丢失可读性。
- **字库细节**：源 LRC 中的 `Je t’aimais` 使用弯引号，16 px 二值化后会出现断口；只在**显示层**替换为直引号 `'`，源文件未动。
- **边界**：制作名单不会作为歌词出现；歌后只留一句结束语。

## 徒步段：如何解决拖沓

160.9 – 188.2 秒（歌里的「寻找你」到「刻在我心底的名字」）不再用少数长镜头硬撑，而是：

| 绝对时间 | 镜头 | 景别 / 内容 | 相邻变化 |
| --- | --- | --- | --- |
| 160.92 – 166.20 | 城市人海 | 全景；伞、行人、成年他在移动 | 从室内切到雨街 |
| 166.20 – 169.80 | 她的玻璃倒影 | 极近景；窗框、雨、脸部 | 人海 → 单张脸 |
| 169.80 – 172.49 | 水洼与鞋 | 近景；霓虹倒影、路过的鞋、他的鞋 | 脸 → 脚 |
| 172.49 – 177.20 | 山道 | 大远景；之字形山路、两个小小的人 | 城市 → 山 |
| 177.20 – 179.80 | 靴子与小腿 | 低机位特写；两双靴、草、步态 | 大远景 → 脚边 |
| 179.80 – 182.60 | 风与草 | 大远景；山脊、两个行走的人、风线 | 近 → 远 |
| 182.60 – 185.40 | 靠近 | 中景；两人逐渐缩短距离 | 远 → 中 |
| 185.40 – 187.02 | 手 | 极近景；两只手差 12 px，不握住 | 全身 → 手 |
| 187.02 – 188.24 | 呼吸之间 | 紧双人；头部约占画面 1/3，身体被裁掉 | 手 → 脸 |
| 188.24 | 初吻 | 剪影；副歌落下时吻 | 静止 → 释放 |

关键不是「镜头多」，而是相邻镜头在**景别、构图、内容、运动、情绪**上至少变两项：人海的全景 → 单张脸的极近；鞋的近景 → 山的大远；草的风动 → 手的静止；手的未触碰 → 吻的释放。长镜头只留在音乐需要空间的地方（歌后留白、分手后的宿舍）。

## 已实现 / 仍为临时

**已实现**

- 真实 MP3 全程播放、暂停、任意跳转、重播、全屏、键盘操作；以 `audio.currentTime` 为主时钟。
- 11 个连续段落、内部多镜头剪辑；硬切、白闪、交叉淡化、压黑均已接通。
- 41 句歌词运行时同步、+0.08 显示偏移、底部安全区、自适应压暗、歌后停止。
- 7 句头部对白气泡、手机内聊天、电话表白、通话计时、占位名揭晓、歌后结束语。
- 徒步段 9 个镜头的重新分镜与不同景别。
- V1（`animatic/`）与冻结备份（`animatic-v1/`）未被改动。

**仍为临时**

- 角色表演来自既有 48 × 64 精灵表的有限帧；行走、呼吸、眨眼是循环，不是逐帧新画。
- 伞、水洼、鞋与小腿、手、钥匙、纪念册肖像等为程序化像素图形，属于分镜占位。
- 初吻是色块剪影；部分近景的肩线 / 脖颈仍是临时修补。
- 徒步靴子镜头的胫部用同色渐隐模拟景深，是权宜方案，后续应单独绘制低机位特写帧。
- 音乐节点仍是 `mv_timeline_draft.json` 的候选值，没有重新做音乐分析。
- 全屏按窗口比例缩放；在非整数倍尺寸下使用 `image-rendering: pixelated`，像素可能有轻微不等宽。

## MP4 导出

- 文件：`export/刻在我心底的名字_V2_720p.mp4`
- 规格：1280 × 720，30 fps，H.264 High，AAC 192 kbps / 48 kHz 立体声，05:25.02，约 23 MB。
- 音轨直接来自未修改的 MP3；320.166 秒后补静音至 325 秒。画面按 30 fps 离线渲染，再与音轨合成；`moov` 前置，可任意拖动。
- 完整解码无错误；浏览器中 `duration = 325`，可跳转到 90 / 188.6 / 283.5 / 322.5 / 324.9 秒，音轨同为 325 秒。
- 抽样与原 MP3 的互相关峰值偏差约 21 ms（AAC 编码器固有延迟，小于 1 帧）。
- 导出只读取 MP3 / LRC，未改写源文件；页面播放不依赖导出文件。`window.__ANIMATIC__.renderAt(t)` 是导出用的无音频渲染接口，不改变正常播放。

## 边界

- 不复制、不转码、不修改 MP3 与 LRC；歌词偏移只存在于显示层。
- 不填真实姓名；结尾只留「珍惜那些在你生命中的名字」。
