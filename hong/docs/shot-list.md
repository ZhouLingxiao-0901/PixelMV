## 镜头语言规则

1. **不按歌词逐句换图。** 一个镜头通常覆盖一到两句词；同一镜头内部有连续动作（走、骑、递票、拉票根、呼吸、尘埃）。
2. **重复的空间改变人。** 影院门厅、放映窗、观众席在前后段重复出现，构图相近、站位不同。
3. **红色是物，不是滤镜。** 每个镜头至多一到两个红色锚点；海、雪、城市分别保持青、白、蓝的基调。
4. **字幕安全区。** 歌词固定在画面下缘（y≈307–326），加一层很轻的暗色底；对白气泡只在 y≈120，绝不进入字幕区。
5. **镜头运动少而慢。** 大多数镜头是固定机位加轻微漂移，只有走路、骑车、巴士用横向跟移；转场以硬切为主。
6. **光的方向要一致。** 影院内以银幕/放映灯为唯一主光；海边以太阳为唯一主光；城市以窗为唯一主光。

## 修改方法

- 改镜头时间或顺序：编辑 `js/timeline.js` 的 `SHOTS`。
- 改转场：编辑 `TRANSITIONS`（`dip / cross / flash / cut / fadeOut`）。
- 改对白：编辑 `DIALOGUE`（`start/end/who/text/bx/by/tipX`）。
- 改歌词时间：编辑 `assets/audio/罗言 - 红.lrc`，运行时自动重新解析，不需要改代码。
- 改画面：在 `js/scenes/*.js` 中找到对应 `render` 函数；`shot` 数据里 `render` 字段就是函数名。
