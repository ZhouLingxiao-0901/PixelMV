# 《红》故事与人物设定

> 这是为歌曲写的**原创虚构故事**。人物、影院、对白都不来自罗言的经历；这句声明只放在播放器的“关于”面板，片尾不再重复。

## 一句话故事

海边小城的老影院要放最后一场电影。曾经在这里相爱的放映员苏棠和声音采集师沈野都回来了，隔着一个空座看完同一部片子，然后各自回到自己的生活。

## 世界

- **老影院**：一座只有一块银幕的老影院，35 毫米放映机，红色绒面座椅，门厅里有海报、挂钟和售票窗口。没有店名招牌，门口只亮着“影院”两个字。
- **海边小城**：影院离海骑车十分钟。海边有旧木栈桥、粉色的黄昏和很软的云。
- **城市**：沈野后来工作的地方。录音棚、出租屋、夜里亮着的窗、橱窗里的倒影。
- 时间：当代。手机、耳机与老放映机同时存在；这正是两人分开的原因之一。

## 人物

> **画法**：影像里两个人都是桌面宠物风格的像素小螃蟹——他是橙色，她是粉色；红围巾、长发这些写在设定里的东西，在画面中换成她的红蝴蝶结、他壳上的红线缆。下面写的是人物本身，不是他们被画成什么样。造型见 `js/crab.js` 与 README 的“改人物”。

### 苏棠 · 26 岁 · 影院售票员，后来兼放映

- **外形**：长发，常穿锈红色外套，围一条红围巾；手指上常有铅灰，因为总在画明信片。
- **习惯**：不爱说长句。等人时把票根一张张码齐；开心的时候画海，不写地址。放映前会用手背试一下机器温度。
- **想要**：把影院、把这个人、把这套熟悉的生活留在原地。
- **害怕**：自己只是别人路过的一站。
- **缺陷**：把“那就别回来了”当成挽留的测试，说出口却成了判决。
- **变化**：从等一个人回来，到允许自己把最后一场放完。她没有烧掉过去，也没有原地不动——她留下了影院，但不再等人。

### 沈野 · 28 岁 · 声音采集师

- **外形**：深蓝外套，领口有一小截红；耳机常年挂在脖子上；随身带录音机和一卷线。
- **习惯**：先录音，后说话。会把生活里的声音编号存档：放映机的咔哒声、海、雨、她笑的那一下。
- **想要**：做出一点能被听见的东西，证明“出去”是对的。
- **害怕**：回去时发现门已经锁了。
- **缺陷**：他习惯解释，而不是听。他说“我只是想让我们过得好一点”，这句话是真的，也是没用的。
- **变化**：从“我好像做到了我想要的样子”，到明白代价是什么。他留下了票根，却没有跨过那个空座。

### 两个人之间

- **相遇**：沈野来影院采放映机的声音；苏棠卖给他一张 7:10 的票。票根是他们第一次说话的理由。
- **相爱**：骑车去海边，她把粉色天画在明信片上，他把海录进机器。两个人一个收集画面，一个收集声音。
- **分裂**：城里来了工作机会。他认为离开是为了两个人；她认为留下才是。谁都没有错，所以谁都无法说服谁。
- **破裂**：门厅里最后一次争吵。她说“你从来没打算留下”，他说“我只是想让我们过得好一点”，她说“那就别回来了”。他拖着箱子走了。
- **之后**：他在城市剪海的声音，耳机里一直是海；她继续放映，影院却要关门了。散场后她把围巾留在座椅上；他打包设备时把票根放进“声音”纸箱。
- **最后一场**：影院重映。两个人隔着一个座位坐着。散场时她把一张完整的票根留在座位上；他在海边坐到天亮。
- **结尾**：天亮的海边，两个人隔着很远的距离站着，都面向海，没有拥抱，也没有说话。沙里有一张票根。**不复合**，但也没有互相毁掉。

## 视觉母题

| 母题 | 出现 | 含义 |
| --- | --- | --- |
| 红 | 座椅、票根、围巾、霓虹、领口、放映灯 | 不是“悲伤”的颜色，而是“还留着”的东西 |
| 票根 / 7:10 | 售票窗口、撕开、纸箱、座位、沙里 | 两个人共同的第一个证据 |
| 红围巾 | 空座、海边、重映 | 她留下的温度；他后来也戴红围巾，颜色相同，来历不说破 |
| 放映机与光束 | 片头、放映室、重映 | 画面 / 记忆 / 她选择的留下 |
| 录音机与波形 | 城市、海边、结尾 | 声音 / 记录 / 他选择的离开 |
| 粉色天 | 海边、明信片、银幕上的海 | 全片最柔软的记忆层，只属于过去 |
| 空座 | 散场、重映 | 两个人之间那一个座位的距离 |
| 雪 | 争吵后的闪回 | “爱她下雪也宁愿光着脚”——爱的自我损耗，不是天气写实 |

## 对白原则

- 全片只有 **5 句**对白，集中在两次争吵（约 1:22 与 1:41）。
- 气泡很小，锚在人物头顶上方，绝不进入字幕区，也不遮脸。
- 对白不复述歌词：歌词说“最恶毒的话”，对白只给一句“那就别回来了”。
- 其余全部交给画面、声音和留白。

## 结局说明

结尾故意不回答“他们有没有再在一起”。可以确定的是：

1. 两个人都来了最后一场；
2. 她留下了票根，他带走了另一张；
3. 天亮时他们站在同一片海边，但没有走近。

这不是“放下”的胜利，也不是“遗憾”的惩罚。它只是两个人在同一首歌结束后，各自还活着。
