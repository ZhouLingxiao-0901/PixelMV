# 《刻在我心底的名字》· 动态分镜 V1（Animatic）

独立于现有 40 秒样片的可播放动态分镜。使用真实 MP3 作为主时间轴，从歌曲开头连续播放到歌后留白与结束文字。

- 本地地址：<http://127.0.0.1:8123/animatic/>
- 页面标题：**刻在我心底的名字 · 动态分镜 V1**
- 画布：640 × 360，整数倍最近邻放大，保持像素边缘
- 总时长：**05:25.0**（325.0 秒）
- 真实音轨：`assets/audio/卢广仲 - 刻在我心底的名字.mp3`，时长 320.165792 秒
- 歌后留白：320.166 – 322.0 秒纯黑静默；322.0 秒起仅显示「珍惜那些在你生命中的名字」

> 这是 **Animatic V1**，不是最终逐帧动画。场景、构图、镜头节奏与声音关系已经可播放；角色仍是复用精灵表中的少量帧，近景是放大裁切加临时遮挡，属于待替换的临时表演。

## 操作

| 操作 | 方式 |
| --- | --- |
| 播放 / 暂停 | 点击「播放」按钮，或点击画面，或按空格 |
| 从头重播 | 「重播」按钮，或按 `R` |
| 拖动进度 | 拖动下方进度条，任意位置可跳转 |

进度条与时间显示精确到 0.1 秒。页面只展示场次和时间，不包含任务栏、血条、地图或其他游戏 UI，也没有额外剧情解说字幕。对白只在画面下方短暂出现，属于创作提案。

## 音画同步

- MP3 在启动时通过 `fetch` 读入同源 Blob，再交给 `<audio>`，解决本地静态服务器不支持 HTTP Range 时拖动进度条无法跳转的问题。
- 播放时以 `audio.currentTime` 为主时钟；画面不会自行漂移。
- 歌后（320.166 秒之后）改用墙钟计时，因此即使窗口被系统降帧，留白长度与结束文字的出现时间仍然正确。
- 页面另有一个低频看门狗：当 `requestAnimationFrame` 被浏览器节流时，仍按音频时间推进画面与进度条。

## 已实现 / 仍为临时分镜

**已实现**

- 真实 MP3 全程播放、暂停、任意跳转、重播、全屏、键盘操作。
- 11 个连续场景、12 个页面节点，完整覆盖 0 – 325 秒；场次之间使用硬切、白闪、交叉淡化、压黑。
- 角色位置、双人同框、分屏、手机光、桌面台灯、雨雪、天台、毕业照、宿舍熄灯等构图与光线关系。
- 名字悬念：只在 01 提问并切断，09 才以占位名揭晓；结尾只留一句文字。
- 高三段以同框、并肩、走路、毕业照等画面承载幸福感，不依赖甜言蜜语。
- 分手段保持克制：分屏、扣下的手机、各自走开、楼体熄灯；没有争吵、哭喊、复合或编造的分手对白。

**仍为临时**

- 角色表演来自既有 48 × 64 精灵表的少量帧，尚未逐帧绘制新的肢体表演；行走/呼吸/眨眼为有限循环。
- 特写使用整帧放大或头肩裁切，部分近景的颈部与肩线仍是临时修补，后续需要单独绘制特写帧。
- 部分群众、纸飞机、彩带、三脚架、宿舍家具为程序化像素图形，属于分镜占位。
- 05 的初吻是色块剪影方案；07 的毕业照是合成蒙太奇；09 的纪念册为占位排版。
- 音乐节点仍是候选：`assets/audio/mv_timeline_draft.json` 与 `docs/music_timeline_draft.md` 未经重新分析或改写。
